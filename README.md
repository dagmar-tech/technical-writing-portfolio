# Technical Writing Portfolio

A collection of technical documentation, tutorials, documentation automation projects, and practical software tools.

**Live website:** [Technical Writing Portfolio](https://dagmar-tech.github.io/technical-writing-portfolio/)

## About

I work at the intersection of technical documentation, product education, and software technology. My background includes technical writing, conversational AI, computational linguistics, technical support, and knowledge engineering.

I enjoy investigating how software works, turning complex technical concepts into clear and practical documentation, and building tools that make documentation and support workflows more efficient.

This repository brings together examples of my work in technical documentation, instructional content, documentation automation, and Python-based tooling.

## Samples

### Technical documentation and tutorials

- **[Releasing a versioned Phrasebook package](tutorials/releasing-a-versioned-phrasebook-package.md):** A step-by-step guide to preparing and validating resources, extracting files, using Git and pull requests, and completing quality assurance (QA).

- **[Grafana Fundamentals: hands-on documentation review](projects/grafana-fundamentals-tutorial-review/README.md):** An independent, hands-on review of Grafana's Fundamentals tutorial, identifying usability issues, outdated instructions, and opportunities to improve the learning experience.

### Instructional design and product education

- **[Troubleshooting unexpected search results](projects/troubleshooting-unexpected-search-results/README.md):** A structured learning resource that guides readers through investigating and troubleshooting unexpected search behavior.

### Documentation automation and tooling

- **[Documentation release pipeline](projects/docs-release-pipeline/README.md):** A documentation workflow using GitHub Actions and AI-assisted drafting to support automated checks and more efficient content maintenance.

- **[Outdated reference finder](projects/outdated-reference-finder/README.md):** A Python tool that identifies potentially outdated company-name references in content, generates prioritized CSV reports, and supports human review before changes are applied.
