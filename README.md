# Technical writing portfolio

This repository contains selected samples of technical documentation, tutorials, and practical software projects.

## About

I have experience in conversational AI, technical support, language engineering, and automation. I enjoy figuring out how software works and explaining it clearly so readers can get things done.

## Samples

### Tutorials

- **[Releasing a versioned Phrasebook package](tutorials/releasing-a-versioned-phrasebook-package.md):** A step-by-step guide to preparing and validating resources, extracting files, using Git and pull requests, and completing quality assurance (QA).

### Projects

- **[Outdated reference finder](projects/outdated-reference-finder/README.md):** A Python tool that identifies potential outdated company-name references in content, generates prioritized CSV reports, and supports human review before changes are applied.

## Notes

The tutorial uses fictional scenarios, products, tools, file formats, and data created for this portfolio. The outdated-reference finder uses fictional company names, ticket keys, and sample content. Its approach is based on my professional experience, but the demo code and data were created from scratch and contain no employer content.
