# Troubleshooting Unexpected Search Results

## Overview

A scenario-based e-learning minicourse designed for customer-facing technical teams who need to investigate unexpected e-commerce search results.

The course teaches an evidence-first troubleshooting approach, helping learners distinguish between retrieval and ranking issues before making changes.

## Learning objectives

By the end of the course, learners should be able to:

- Identify the symptoms of unexpected search behavior.
- Distinguish retrieval issues from ranking issues.
- Follow a structured troubleshooting process.
- Gather relevant evidence before escalating or changing configuration.
